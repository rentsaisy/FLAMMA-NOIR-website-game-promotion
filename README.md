# FLAMMA NOIR

FLAMMA NOIR is a promotional website for a cinematic visual novel. The website introduces the game's noir-inspired world, story, characters, combat system, and development team through a dark pixel-art visual style.

## Overview

The website presents:

- The FLAMMA NOIR hero section with a link to play the game on itch.io.
- The story of Katerine Ivanovna and the NOIR investigation team.
- Interactive character cards for protagonists and antagonists.
- A character details modal with each character's name, role, image, and description.
- A features section highlighting the Type Advantage Combat System, the NOIR world, and branching story elements.
- Developer profiles with links to their GitHub accounts.
- A feedback form that prepares a message in the visitor's default email application.
- Responsive navigation and layout for desktop and mobile screen sizes.

## Technologies

## Running the Website

Because this is a static website, it can be opened directly in a browser:

1. Clone or download the repository.
2. Open `index.html` in a modern web browser.

For a local development server, run any static file server from the project directory. For example, if Python is installed:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in a browser.

## Interactions

- Use the navigation links to move between page sections.
- On smaller screens, use the menu button to open or close the navigation.
- Select a character card to view its details in a modal dialog.
- Press `Escape` or select the close button to close the character modal.
- Submit the feedback form to open a pre-filled email in the default email application.
